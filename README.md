# MIT Open Learning Library – Quantum Information & Computation, Machine Learning, etc

This repository documents my completed coursework from the **MIT Open Learning Library (OLL)** in **Quantum Information Science**, **Quantum Computation**, and **Quantum Error Correction**.

These courses were completed as part of my long-term research and platform work on **Quantum AI (QAI)**, **hybrid quantum–classical systems**, and **scalable computational models** used in the **QAI Lab** and **Universal R&D Product Factory**.

All courses listed below are MIT-authored, graduate-level, mathematically rigorous, and assessment-driven.
